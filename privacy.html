1. 我们是谁，这份政策管什么

ALTER（中文名「另一个我」）是一款面向 12–18 岁青少年的「英语分身」剧情口语练习工具。本政策适用于 ALTER 的 Web / PWA 版本（当前公开体验地址：elizabeth819.github.io/alter-english）以及本站点（ALTER 落地页与合规文档）。

我们遵循《中华人民共和国个人信息保护法》《中华人民共和国未成年人保护法》等法律法规中「最小必要」的原则：能不做的事就不做，能不收的信息就不收。

2. 我们不收集哪些信息

使用 ALTER 和本站点，不需要注册，也不需要提供以下任何信息：

  • 姓名、昵称、头像、性别、生日；
  • 手机号、邮箱、微信号、QQ 号；
  • 身份证号、学籍、学校、年级、住址；
  • 地理位置、通讯录、相册、摄像头；
  • 录音、声纹或任何形式的语音数据。

我们没有账号体系，也没有服务器端的学习数据库。你不需要「登录」，因此也不会产生账号密码。

3. 只存在你设备上的数据

为了让你下次打开还能接着演，ALTER 会在你浏览器的本地存储（localStorage）中保存以下数据。这些数据不会上传到我们的服务器，我们也无法远程读取：

数据内容用途
剧情进度已完成的季 / 集 / 幕，当前进度下次打开继续
成长数据XP、连击天数、地道句数本机展示成长记录
选择记录每集二选一的分支选择让下一集承接你的选择
句子本你收藏的句子本机复习与朗读
偏好设置人设、卡片配色等保持你的使用偏好

以上数据仅用于在你的设备上呈现功能，不用于广告、画像、信用评估或任何自动化决策。

4. 朗读、录音与麦克风

ALTER 的英文朗读使用浏览器自带的 Web Speech API（语音合成）完成。我们不调用麦克风，不录音，也不保存你的声音。当前版本不提供录音打分功能。

语音合成由你的浏览器或操作系统提供，部分浏览器可能调用其厂商的在线语音服务来处理待朗读的文本。这部分处理受浏览器 / 操作系统厂商的隐私政策约束，ALTER 不接触、不存储相关音频或文本记录。

如果未来上线跟读或语音识别功能，我们会先更新本政策、单独说明权限用途，并在获得你和监护人同意后才启用。

5. 名场面卡与分享

名场面卡由浏览器本地 Canvas 生成，全程在你的设备上完成。只有当你主动点击「保存」或「分享」时，图片才会离开浏览器，进入你的相册或你选择的社交平台。我们不会自动上传、收集或公开展示你的卡片。

6. 本站点与托管服务

本站点是纯静态页面，没有植入统计、广告、热力图或第三方追踪代码，也不使用 Cookie 做用户追踪。

站点由 GitHub Pages 托管。作为托管服务商，GitHub 可能按其自身隐私政策记录基础访问日志（例如 IP 地址、访问时间、浏览器类型）。我们无法读取这些日志中的个人身份信息，也不会将其用于用户画像。GitHub 的隐私实践请参见其官方隐私声明。

7. 我们不会做的事

  • 不向任何第三方出售、出租或交换个人信息；
  • 不接入广告 SDK，不做个性化广告；
  • 不提供陌生人社交、群聊、公开 UGC 展示或排行榜；
  • 不进行与学习无关的数据采集；
  • 不把学习数据用于保险、信贷、招聘等场景。

8. 数据的删除与设备共用

因为数据只存在本机，删除也很直接：

  • App 内清除：在「我的 / 设置」中清除本地数据；
  • 浏览器清除：清除该站点的浏览数据（Cookie 与站点数据）即可删除全部进度；
  • 卸载 / 换设备：数据不会跟随，需重新开始。

如果孩子与家人共用一台设备，建议为设备设置锁屏密码，或使用浏览器的独立用户空间。共用设备时，其他使用者可能看到本机的学习记录与句子本。

9. 未成年人保护

ALTER 面向 12–18 岁青少年。我们的设计原则是：不收集个人信息，就不存在未成年人敏感个人信息被滥用的风险。

  • 不满 14 周岁的用户，应在监护人同意和指导下使用；
  • 我们不会要求未成年人提交任何身份信息，也不会向其推送营销信息；
  • 涉及付费时，年付与家庭版默认走家长确认，单笔超过 100 元需监护人验证；
  • 如监护人发现孩子在未经同意的情况下付费，可按退款政策申请处理。

10. 你的权利

由于我们不持有你的个人信息，你对本地数据拥有完全控制权：可以随时查看、修改（例如删除句子本条目）或清除。若你认为我们的产品或页面存在隐私问题，可通过下方渠道联系我们，我们会在收到后 15 个工作日内答复。

11. 政策更新

如果产品功能发生变化（例如未来引入账号、云同步或语音识别），我们会更新本政策，并在站内与 App 内以显著方式提示。涉及处理目的、方式或信息类型的重大变更，会重新取得必要同意。
